# Bankruptcy Prediction Using Machine Learning

## Overview

This project applies data analysis and machine learning techniques to financial data to identify patterns associated with company bankruptcy and predict whether a company is likely to fail or remain financially stable.

The project covers the complete data science workflow, from exploratory data analysis and feature engineering to model development, evaluation, and recommendations.

## Objectives

- Explore financial indicators associated with company bankruptcy.
- Identify patterns and trends in company financial performance.
- Prepare and transform data for machine learning.
- Develop a classification model to predict company bankruptcy.
- Evaluate model performance and identify areas for improvement.

## Project Workflow

### 1. Exploratory Data Analysis (EDA)
- Examine dataset structure and data types.
- Investigate missing values and data quality.
- Analyse financial indicators and their distributions.
- Explore bankruptcy trends across different years.
- Compare financial characteristics of failed and surviving companies.

### 2. Feature Engineering
- Clean and prepare financial variables.
- Transform relevant features.
- Encode categorical variables.
- Prepare the target variable for classification.
- Select relevant features for modelling.

### 3. Model Development
- Prepare training and testing datasets.
- Select appropriate machine learning algorithms.
- Train classification models.
- Generate predictions using financial indicators.

### 4. Model Evaluation
- Evaluate model performance using classification metrics.
- Analyse the confusion matrix.
- Assess precision, recall, and F1-score.
- Identify model strengths and limitations.

### 5. Conclusion and Recommendations
- Summarise key findings from the analysis.
- Highlight financial indicators associated with bankruptcy.
- Discuss the model's predictive performance.
- Provide recommendations for future improvements.

## Dataset

The dataset contains financial information about companies, including indicators such as:

- Current Assets
- Cost of Goods Sold
- EBITDA
- Net Income
- Other financial performance indicators

The target variable represents company status, categorised as **Failed** or **Alive**.
